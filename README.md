# Obsidian Starter Vault / 配置模板

本模板基于已有 Obsidian 设置整理，保留 AnuPpuccin、Velocity 主题、7 个 CSS 片段和已安装的第三方插件。

## 使用方法
1. 下载并解压本 ZIP。确保 Finder 已显示隐藏文件（Command + Shift + .）。
2. 新建空文件夹作为 Obsidian 仓库，将解压出的 `.obsidian` 文件夹复制到仓库根目录。
3. 用 Obsidian 打开该文件夹，按提示确认第三方插件信任，并检查外观 → CSS 代码片段。
4. 按需新建文件夹。
5. Chatting with AI、Copilot 需要各自重新登录或配置.

## 隐私与可移植性
注意：插件本体随包提供，使用前请确认各插件的许可证及来源。若公开发布，推荐在仓库中说明插件原始项目链接和许可证。
